Cloud Mail REST API v2

Base URL：https://mail.airoute.kdns.fr/api/v1 · OpenAPI 3.1 JSON

Header：Authorization: Bearer YOUR_API_KEY

Key 管理：用户 Key 在“个人设置”中管理，只访问本人数据；管理员 Key 在管理员“API Key 管理”菜单中管理，可调用紫色标记的 /admin/*。
用户 REST API 与管理员 REST API 使用两个独立开关，关闭任一开关只影响对应类型的 Key。IP 白名单为空表示不限；有效期可永久或指定时间。服务端保存可查看的明文 Key，并记录最后成功请求 IP、时间和脱敏后的请求内容。

GET /me — 获取当前用户

返回 API Key 所属用户的基本信息。 只能访问 API Key 所属用户自己的资源。

curl 示例

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/me" \
  --header "Authorization: Bearer YOUR_API_KEY"

GET /accounts — 查询邮箱账号

查询主账号和子账号。使用游标分页。 只能访问 API Key 所属用户自己的资源。

参数位置必填类型说明示例
cursorquery否integer上一页返回的 nextCursor；第一页省略。123
limitquery否integer每页数量，1-50，默认 20。20

curl 示例

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts?limit=20" \
  --header "Authorization: Bearer YOUR_API_KEY"

POST /accounts — 批量创建子邮箱

请求体可直接传数组，也可传 {emails:[...]}；每次 1-50 个。已被当前用户删除的子邮箱可用相同地址重新添加，恢复原 accountId，并可通过 name 指定显示名称；其他用户删除的地址不可抢占。响应统一返回 items 数组。只能访问 API Key 所属用户自己的资源。

请求体

[
  "batch-one@mail.airoute.kdns.fr",
  {
    "email": "batch-two@mail.airoute.kdns.fr",
    "name": "Batch Two"
  }
]

curl 示例

curl --request POST \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '["batch-one@mail.airoute.kdns.fr",{"email":"batch-two@mail.airoute.kdns.fr","name":"Batch Two"}]'

PATCH /accounts/{accountId} — 修改邮箱账号

name 会立即修改本人有效邮箱账号的显示名称（去除首尾空格，最长 30 个字符）；后续新邮件仍归属同一 accountId，并可用新名称筛选。allReceive 为 0/1，用于设置聚合收件账号。只能访问 API Key 所属用户自己的资源。

参数位置必填类型说明示例
accountIdpath是integer本人邮箱账号 ID。2

请求体

{
  "name": "Automation",
  "allReceive": 0
}

curl 示例

curl --request PATCH \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts/2" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"name":"Automation","allReceive":0}'

DELETE /accounts/{accountId} — 删除子邮箱账号

软删除本人子邮箱账号并关闭聚合收件；主账号不能删除。删除后可由原所有者通过 POST /accounts 使用相同邮箱地址恢复，历史邮件状态不变，新邮件可继续接收。只能访问 API Key 所属用户自己的资源。

参数位置必填类型说明示例
accountIdpath是integer本人子邮箱账号 ID。2

curl 示例

curl --request DELETE \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts/2" \
  --header "Authorization: Bearer YOUR_API_KEY"

GET /emails — 筛选邮件

支持按时间、主/子账号 ID、账号名称或完整邮箱筛选。 只能访问 API Key 所属用户自己的资源。

参数位置必填类型说明示例
cursorquery否integer上一页返回的 nextCursor（emailId）。999999
limitquery否integer每页数量，1-50，默认 20。20
accountIdquery否integer主账号或子账号 ID。1
accountNamequery否string账号显示名或完整邮箱；与 accountId 二选一。admin
typequery否integer0=收件，1=发件。0
unreadquery否integer0=未读，1=已读。0
startTimequery否string起始时间（含），格式 YYYY-MM-DD HH:mm:ss。2026-08-01 00:00:00
endTimequery否string结束时间（含），格式 YYYY-MM-DD HH:mm:ss。2026-08-31 23:59:59

curl 示例

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/emails?cursor=999999&limit=20&accountName=admin&type=0&unread=0&startTime=2026-08-01+00%3A00%3A00&endTime=2026-08-31+23%3A59%3A59" \
  --header "Authorization: Bearer YOUR_API_KEY"

{
  "emailIds": [
    123,
    124,
    125
  ]
}

  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"emailIds":[123,124,125]}'

参数位置必填类型说明示例

  "type": 1,

curl --request POST \
  --url "https://mail.airoute.kdns.fr/api/v1/admin/users" \

GET /admin/emails — 管理员查询全站邮件

可查看全部邮件或按用户、账号和时间筛选。 必须使用管理员专用 API Key。

参数位置必填类型说明示例
limitquery否integer返回数量，1-100。50
userIdquery否integer用户 ID。2
userEmailquery否string用户登录邮箱。user@mail.airoute.kdns.fr
accountIdquery否integer邮箱账号 ID。3
accountNamequery否string账号名称或完整邮箱。user@mail.airoute.kdns.fr
startTimequery否string起始时间（含）。2026-08-01 00:00:00
endTimequery否string结束时间（含）。2026-08-31 23:59:59

curl 示例

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/admin/emails?limit=50&userEmail=user%40mail.airoute.kdns.fr&accountName=user%40mail.airoute.kdns.fr&startTime=2026-08-01+00%3A00%3A00&endTime=2026-08-31+23%3A59%3A59" \
  --header "Authorization: Bearer YOUR_API_KEY"

PATCH /admin/settings — 管理员修改 REST API/多号设置

只接受 0/1。restApiEnabled:0 开启用户 REST API，只控制用户 Key；adminRestApiEnabled:0 开启管理员 REST API，只控制管理员 Key；manyEmail:0 开启多号模式；addEmail:0 允许添加邮箱。两个 API 开关互不影响。必须使用管理员专用 API Key。

请求体

{
  "restApiEnabled": 0,
  "adminRestApiEnabled": 0,
  "manyEmail": 0,
  "addEmail": 0
}

curl 示例

curl --request PATCH \
  --url "https://mail.airoute.kdns.fr/api/v1/admin/settings" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"restApiEnabled":0,"adminRestApiEnabled":0,"manyEmail":0,"addEmail":0}'
