v1

Cloud Mail REST API

通过 API Key 管理当前用户自己的邮箱账号、邮件与附件。

Base URL：https://mail.airoute.kdns.fr/api/v1 · OpenAPI 3.1 JSON

1. 开启与创建 API Key

  1. 超级管理员在“系统设置”中开启“用户 REST API”。
  2. 用户进入“个人设置 → API Key”。
  3. 创建一个命名 Key，例如“家中服务器”或“手机自动化”。
  4. 立即复制完整 Key；完整内容只显示一次。
管理员关闭 REST API 后，所有 Key 会立即暂停使用；重新开启后，未吊销的 Key 会恢复。 每个 Key 可单独吊销。

2. 鉴权

每个请求都必须携带标准 Bearer 请求头：

Authorization: Bearer cma_PUBLIC_ID_SECRET

示例：

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts" \
  --header "Authorization: Bearer YOUR_API_KEY"

API Key 只能操作所属用户自己的数据。猜测其他用户的 accountId、emailId 或 attachmentId 会返回 404。

3. 端点

方法 路径 说明
GET /me 当前 API Key 所属用户
GET /accounts 分页查询自己的邮箱账号
POST /accounts 创建自己的子邮箱账号
PATCH /accounts/{accountId} 修改账号名称或聚合收件设置
DELETE /accounts/{accountId} 删除自己的子账号；主账号不可删除
GET /emails 查询邮件摘要，支持游标、账号、收发类型和已读状态筛选
GET /emails/{emailId} 读取单封邮件正文
PATCH /emails/{emailId}/read 标记邮件已读
DELETE /emails/{emailId} 软删除邮件
GET /emails/{emailId}/attachments 查询附件元数据
GET /emails/{emailId}/attachments/{attachmentId} 经过所有权校验后下载附件

4. 常用请求

创建子邮箱

curl --request POST \
  --url "https://mail.airoute.kdns.fr/api/v1/accounts" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"email":"automation@mail.airoute.kdns.fr"}'

查询邮件

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/emails?limit=20" \
  --header "Authorization: Bearer YOUR_API_KEY"

读取单封邮件

curl --request GET \
  --url "https://mail.airoute.kdns.fr/api/v1/emails/123" \
  --header "Authorization: Bearer YOUR_API_KEY"

删除邮件

curl --request DELETE \
  --url "https://mail.airoute.kdns.fr/api/v1/emails/123" \
  --header "Authorization: Bearer YOUR_API_KEY"

5. 分页与状态码

  • 默认每页 20 条，limit 最大为 50。
  • 账号列表使用向前游标；邮件列表使用降序 emailId 游标。
  • 400 参数错误；401 Key 无效或已吊销。
  • 403 REST API 已关闭或用户被禁用。
  • 404 资源不存在或不属于当前用户。
  • 409 资源冲突，例如尝试删除主邮箱账号。

6. 安全建议

  • 不同设备或程序使用不同的命名 Key。
  • 不要把 Key 写入 Git、前端源码、公开日志或 URL 查询参数。
  • 怀疑泄露时立即在个人设置中吊销对应 Key。
  • 服务端只保存 Key 哈希；完整 Key 无法找回，只能重新创建。
